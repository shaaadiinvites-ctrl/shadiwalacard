# SEO Skills Hub (Zero-API)

Welcome to the zero-API SEO optimization hub. This suite provides production-grade, API-free search engine optimization workflows tailored directly to your codebase and web applications.

## Specialized Skills Index

| Skill | Focus Area | When to Use |
|---|---|---|
| [`seo-schema`](../seo-schema/SKILL.md) | Structured Data (JSON-LD) | Rich snippets: Event, Product, LocalBusiness, Article, FAQ, Breadcrumbs |
| [`seo-images`](../seo-images/SKILL.md) | Image SEO & Performance | Alt-text audit, Next.js `<Image />` LCP/CLS optimization, WebP/AVIF |
| [`seo-technical-audit`](../seo-technical-audit/SKILL.md) | Codebase Technical SEO | Metadata, Open Graph, canonicals, H1 hierarchy, indexability checks |
| [`seo-sitemap`](../seo-sitemap/SKILL.md) | Sitemaps & Robots | Next.js `app/sitemap.ts` and `app/robots.ts` generation and validation |
| [`seo-sxo`](../seo-sxo/SKILL.md) | Search Experience & Intent | Dwell time, readability, 4-persona scoring, conversion UX |

## Quick Decision Tree

- **"Add structured data / rich snippet for wedding invitations"** -> Run [`seo-schema`](../seo-schema/SKILL.md)
- **"Check my images or fix layout shifts from photos"** -> Run [`seo-images`](../seo-images/SKILL.md)
- **"Is my site ready for search engines?"** -> Run [`seo-technical-audit`](../seo-technical-audit/SKILL.md)
- **"Generate or fix my sitemap and robots.txt"** -> Run [`seo-sitemap`](../seo-sitemap/SKILL.md)
- **"Improve copy, readability, and user conversion"** -> Run [`seo-sxo`](../seo-sxo/SKILL.md)
