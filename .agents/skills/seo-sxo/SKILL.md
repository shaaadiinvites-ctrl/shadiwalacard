# Search Experience Optimization (SXO) (Zero-API)

Search Experience Optimization (SXO) merges SEO (getting discovered) with UX/CRO (satisfying user intent and converting visitors). Instead of relying on external API rankings, SXO diagnoses how well the page answers the user's implicit intent once they land.

Authoritative rubrics:
- 4-Persona Rubric: [persona-rubrics.md](./references/persona-rubrics.md)
- Page-Type Architectural Patterns: [page-type-patterns.md](./references/page-type-patterns.md)

## The 4-Persona Scoring Matrix (0–10 each)

1. **The Skimmer**
   - *Goal*: Extract the core message or answer in under 30 seconds.
   - *Check*: Is there a clear headline, bulleted takeaways, bold highlights, visual card previews, and tight copywriting above the fold?
2. **The Researcher**
   - *Goal*: Compare features, specifications, and evidence.
   - *Check*: Are feature comparisons, step-by-step walkthroughs, and clear FAQs easily discoverable?
3. **The Buyer**
   - *Goal*: Convert with high confidence.
   - *Check*: High-contrast CTA buttons, clear pricing/options, social proof, testimonials, and zero hidden surprises.
4. **The Validator**
   - *Goal*: Verify credibility and trust.
   - *Check*: Contact info, about page, secure checkout signals, responsive mobile experience, and Schema.org structured data.

## Deliverable
1. Persona Scorecard (0–10 on each persona with weighted 0–100 total score).
2. Friction Points & Intent Mismatches.
3. Wireframe / Copy Recommendations to elevate user engagement and dwell time.
