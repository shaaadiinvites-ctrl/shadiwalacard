# Project Rules & Guidelines

## Deployment Protocols
- **Always ask and confirm before deploying to Vercel**: Never execute production or preview deployments (e.g. `vercel deploy`, `vercel --prod`, or deploying via API) without explicitly asking the user and receiving clear, affirmative confirmation.
- **Explain changes prior to deployment**: Before asking for confirmation to deploy, summarize the changes being shipped, what was tested/verified, and any potential side effects.
